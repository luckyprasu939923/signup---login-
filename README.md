# HiHubble Auth Screen

An Expo + React Native (TypeScript) registration/login screen.

## Setup

```bash
npm install
npx expo start
```

Then press `i` for iOS simulator, `a` for Android emulator, or scan the QR code with the Expo Go app.

## Files

- `HiHubbleAuthScreen.tsx` — the full Sign Up / Login screen component
- `App.tsx` — entry point that renders the screen
- `app.json` — Expo app configuration
- `package.json` — dependencies
- `babel.config.js`, `tsconfig.json` — build configuration
